# CZ Leads: пошук клієнтів на сайти

Шукає фірми в Чехії **без сайту, з мертвим або старим сайтом** і складає Excel з контактами.

## Як працює
1. **Firmy.cz** (каталог Seznam, найповніший у Чехії): назва, телефон, email, сайт, IČO.
2. **Аудит сайту:**
   - чи він взагалі є;
   - чи відкривається;
   - чи є HTTPS;
   - чи адаптований під телефон;
   - старий © рік;
   - стара CMS / jQuery / flash;
   - безкоштовний конструктор (webnode, wbs…);
   - швидкість.
3. **Актуальність контактів:**
   - **ARES** (держреєстр): закриті фірми автоматично викидаються, додається ім'я власника;
   - **email**: перевірка, що домен реально приймає пошту (MX);
   - **телефон**: нормалізується, позначається мобільний чи стаціонарний (на мобільний можна писати SMS/WhatsApp).
4. **Excel** (`output/leady_ДАТА.xlsx`):
   - лист **«Ліди»**: тільки потенційні клієнти, найгарячіші зверху;
   - лист **«Усі фірми»**: усе підряд;
   - колонка **«Текст для першого контакту (CZ)»**: готове повідомлення під конкретну проблему фірми;
   - **NEW**: фірма вперше з'явилась (з минулих запусків пам'ятає `seen.json`).

  - шаблонний односторінковий сайт у фрилансера 3 500–8 000 Kč;

Ціни стоять у `START_PRICE` / `STANDARD_PRICE` у `lead_finder.py`. Змінив і хочеш перерахувати вже готовий Excel:
```

```

## Пропозиції: макет сайту + лист
`offers.py` для кожного ліда робить:
- **унікальний макет сайту 1920×1080.** `mockup.py` має 6 арт-напрямів:
  - Editorial: люкс-журнал, фото на весь екран;
  - Arch: бутік, фото в арці;
  - Bold: темний, величезний шрифт;
  - Split: фото + нумеровані послуги;
  - Magazine: сітка фото;
  - Corporate: скляні картки.

  Кожен напрям має кілька палітр і пар шрифтів, а тематичні фото беруться з Unsplash (вільна ліцензія). Для кожної фірми все це комбінується під її нішу, тож однакових макетів практично немає. На макеті назва фірми, телефон, рейтинг, послуги, віджет запису, меню або форми запиту і домен;
- **лист чеською:** яка в них проблема, що отримають, ціна, термін;
- **короткий текст для WhatsApp/SMS.**

```
pip install -r requirements.txt
python -m playwright install chromium
python offers.py output/leady_ДАТА.xlsx            # усі ліди
python offers.py output/leady_ДАТА.xlsx --limit 20 # тільки перші 20
```

Результат лежить у `offers/`:
- `001_nazev-firmy.jpg` …;
- `offers/nabidky.xlsx`: тема, текст листа, WhatsApp-текст, файл картинки.

При першому запуску з'явиться `config.json`, впиши туди своє ім'я, телефон, email. Після цього перезапусти `offers.py`, бо підпис підставляється в листи саме при генерації. Картинки вже є, тому повторний запуск займе секунди.

## Розсилка з твоєї пошти
1. **Gmail:** увімкни двофакторну автентифікацію, потім https://myaccount.google.com/apppasswords → створи «пароль програми» і встав його в `config.json` → `smtp_password`.
   **Seznam:** `smtp_host: smtp.seznam.cz`, `smtp_port: 465`, звичайний пароль.
2. Запуск:
```
python send_offers.py --test tvuj@email.cz   # приклад собі
python send_offers.py                        # подивитись, кому піде
python send_offers.py --send                 # відправити
python send_offers.py --send --status "БЕЗ САЙТУ"   # тільки найгарячіші
```
- **Ліміт:** не більше `daily_limit` (25) листів на день, між листами пауза 1,5–4 хв. Запускай щодня, і він продовжить з того місця, де зупинився.
- **Без дублів:** хто вже отримав лист, записано в `sent.json`, повторно нікому не піде.
- **Відписка:** у кожному листі є фраза «nechcete – odepište ne». Тим, хто відповів «ne», більше не пиши.

⚠️ У Чехії комерційні email без згоди формально заборонені навіть для фірм (zákon 480/2004 Sb.), тому:
- пиши персонально й небагато;
- на «ne» відповідай повагою;
- найгарячіших (без сайту, з мобільним) краще набрати або написати у WhatsApp.

## Запуск (Windows)
1. Встанови Python з python.org (при встановленні постав галочку *Add to PATH*).
2. Подвійний клік на `run.bat`. Без параметрів перевіряє 10 найбільших міст × 25 ніш (це довго, кілька годин).

Швидше запускати точково з командного рядка в цій папці:
```
run.bat --cities Brno --max-pages 3
run.bat --cities Praha Plzeň --niches "kadeřnictví" "autoservis" "zubní ordinace"
```

Параметри:
- `--cities`: міста;
- `--niches`: ніші (будь-які слова, як шукав би на firmy.cz);
- `--max-pages`: скільки сторінок видачі брати на кожен запит (≈15 фірм на сторінку);
- `--include-inactive`: не викидати фірми, закриті за ARES.

Список ніш і міст за замовчуванням задано на початку `lead_finder.py`.

## Поради
- Запускай раз на тиждень: нові фірми будуть позначені **NEW**.
- Колонки «Статус (твій)» і «Нотатки» твої: «дзвонив», «не цікаво», «зустріч».
- Пиши персонально, 10–20 контактів на день. Масова розсилка = спам-фільтр і проблеми з GDPR.
- Firmy.cz запитується з паузою ~1 с, не прибирай її, бо заблокують.
